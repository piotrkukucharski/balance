# Workspace & Budget View Templates (`internal/web/templates/workspace`)

## Overview
Server-side HTML templates for envelope budgeting worksheets, category groups, bucket cards, and targets.

## Interface
- `workspace.html`

## Invariants
- Renders Ready-To-Assign (RTA) banner and interactive envelope balances.

## Side Effects
- None. Static HTML template compilation.

## Verification
