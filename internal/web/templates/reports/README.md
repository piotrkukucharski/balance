# Reports View Templates (`internal/web/templates/reports`)

## Overview
Server-side HTML templates for financial reports (Net Worth, Income vs Expense, Age of Money, Spending Trends).

## Interface
- `reports.html`

## Invariants
- Visualizes chart datasets powered by server-side JSON projection models.

## Side Effects
- None. Static HTML template compilation.
