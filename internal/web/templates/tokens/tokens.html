How to use your Personal Access Token

Authenticate requests by passing the token in the Authorization header. PAT requests are exempt from CSRF checks:

curl -H "Authorization: Bearer bal_pat_your_token_here" \
     -H "Accept: application/json" \
     http://localhost:8080/api/v1/budgets/{{.BudgetID}}
